# AgentStream — 1-minute pitch script

**0:00-0:12**

AI agents now call other agents and APIs on their own. Today's payment tools need humans, and cards or subscriptions are too slow for this.

> AIエージェントは今、自律的に他のエージェントやAPIを呼び出しています。今の決済手段は人間を必要とし、カードやサブスクリプションはこの用途には遅すぎます。

**0:12-0:26**

AgentStream solves this. Agents open real-time payment streams and pay in USDC, per second, only for what they actually use, on Solana.

> AgentStreamはこれを解決します。エージェント同士がリアルタイムの決済ストリームを開き、USDCで、秒単位で、実際に使った分だけ支払います。Solana上で動きます。

**0:26-0:42**

Here's how it works. One agent opens a stream through our SDK. An on-chain escrow holds the funds and releases USDC as time passes.

> 仕組みはこうです。一つのエージェントが私たちのSDKを通じてストリームを開きます。オンチェーンのエスクローが資金を保持し、時間が経つごとにUSDCを放出します。

**0:42-0:54**

Agents also have on-chain identity and reputation, and a dashboard shows live streams, spend rate, and balances in real time.

> エージェントはオンチェーンのアイデンティティと評判も持ち、ダッシュボードでライブのストリーム、支払いレート、残高をリアルタイムで確認できます。

**0:54-1:00**

This is the payment rail for the agent economy. Next, we'll add more tokens and integrate with agent frameworks. Thank you.

> これはエージェント経済のための決済基盤です。次はより多くのトークンへの対応と、エージェントフレームワークとの統合を進めます。ありがとうございました。
